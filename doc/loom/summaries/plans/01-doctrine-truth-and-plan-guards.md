# Plan 01: Doctrine Truth and Plan Guards

## Scope

This plan is stage 1 of the token-optimization programme, and it carries every code and doctrine change in one standard stage, `doctrine-and-guards` [Stage 1](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#1-doctrine-truth-and-plan-guards-doctrine-and-guards)

The plan corrects false or contradictory instructions in the signals, hooks, template, README and two skills, and it deletes the dead memory-summary path [Overview](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#overview)

## Goals

Integration-verify stops telling agents to run `loom knowledge update`, and implementation stages stop curating knowledge [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

The recovery text names the stage's own journal through the `loom memory list --stage` command in the template, the compaction hook and the signal [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

The `found:`, `gotcha:` and `found/gotcha:` note prefixes become one class in the parser [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

A section annotated deprecated, superseded or historical must leave default retrieval, and one fixture test proves it [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

A test fails when a doctrine surface teaches a `loom` subcommand that the CLI lacks [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

## Plan Guards

The bootstrap warning fires only for a missing or scaffold-only knowledge tree, and two version-2 bookend lints require the distill and verify stages [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

A stage `model` outside `haiku`, `sonnet`, `opus` and `fable` is rejected, although the field is already shell-escaped, so the allowlist guards against spawn-time typos rather than injection [Deviations](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#deviations-from-the-metaplan-the-tree-wins)

An archive failure while journals exist stops plan completion and `loom clean` before any deletion, so the journals survive and the step can be retried [Goals](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#goals)

Under the daemon, an archive failure is only logged and the completion marker is still written, which the README states [Deviations](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#deviations-from-the-metaplan-the-tree-wins)

The baseline checks at revision `4cc085b0` show the knowledge check failing on three issues [Baselines](../../../plans/optim-token/archive/DONE-PLAN-01-doctrine-truth-and-plan-guards.md#baselines)
