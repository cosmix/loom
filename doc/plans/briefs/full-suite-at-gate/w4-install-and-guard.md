```rust
/// Remove every `loom-*.md` under `agents_dir` that no embedded agent names.
///
/// A retired or renamed agent (`loom-verifier`, `loom-mechanical-engineer`)
/// otherwise stays installed, and orchestrators keep listing it as a
/// spawnable type. Candidates are directory entries named `loom-*.md` that are
/// regular files or symlinks: an operator's own agents (no `loom-` prefix),
/// directories, and loom's `.bak.<stamp>` copies (the name no longer ends in
/// `.md`) are never touched. The `loom-` prefix does not prove loom wrote a
/// file, so a regular file is backed up first, as `write_assets` does for a
/// differing asset. A symlink is unlinked and never followed, so the target in
/// a dotfiles repository survives.
///
/// Returns the removed paths and the backups taken.
fn prune_stale_agents(agents_dir: &Path, assets: &[Asset]) -> Result<(Vec<PathBuf>, Vec<PathBuf>)> {
    let (mut pruned, mut backups) = (Vec::new(), Vec::new());
    for entry in fs::read_dir(agents_dir)
        .with_context(|| format!("Failed to read {}", agents_dir.display()))?
    {
        let entry =
            entry.with_context(|| format!("Failed to inspect {}", agents_dir.display()))?;
        let file_name = entry.file_name();
        let Some(name) = file_name.to_str() else { continue };
        if !name.starts_with("loom-")
            || !name.ends_with(".md")
            || assets.iter().any(|(key, _)| *key == name)
        {
            continue;
        }
        let path = entry.path();
        let kind = entry
            .file_type()
            .with_context(|| format!("Failed to inspect {}", path.display()))?;
        if kind.is_file() {
            backups.push(super::back_up_asset(&path)?);
        } else if !kind.is_symlink() {
            continue;
        }
        fs::remove_file(&path).with_context(|| format!("Failed to remove {}", path.display()))?;
        pruned.push(path);
    }
    pruned.sort();
    Ok((pruned, backups))
}
```

Notes on the choices:

- `DirEntry::file_type()` does not follow symlinks, so a symlink (live or dangling) is classified as a symlink and `remove_file` unlinks the link itself. `back_up_asset` opens the path and would follow a link, which is why symlinks skip the backup.
- `read_dir` follows a symlinked `agents/` directory itself, which matches `write_assets` writing through it (`claude.rs` doc comment on `write_assets`).
- `write_assets` has already run `create_dir_all` on `agents_dir`, so `read_dir` cannot hit a missing directory.
- The sort makes the report and the test deterministic; `read_dir` order is unspecified.
- `back_up_asset` is `fn` in `install.rs:166`, private to `assets::install`, and reachable from the child module as `super::back_up_asset` (the same call `write_assets` makes at `claude.rs:88`).
- The backup is the one addition beyond the plan text ("removes every `loom-*.md`..."). It costs one `if` branch and one `.bak` file per removed regular file on first run; drop the `kind.is_file()` branch body to a bare removal if the operator wants no backups.

### A2. Test

```rust
/// A retired or renamed `loom-*.md` agent is removed (a regular file after a
/// backup, a symlink without touching its target); a current agent, an
/// operator's own agent and the backups survive, and a second install is a no-op.
#[test]
fn stale_loom_agents_are_pruned_and_other_agents_survive() {
    let temp = TempDir::new().unwrap();
    let paths = paths(&temp);
    let agents = paths.claude_dir.join("agents");
    fs::create_dir_all(&agents).unwrap();
    let shipped = asset_content(crate::assets::CLAUDE_AGENTS, "loom-software-developer.md");
    fs::write(agents.join("loom-foo.md"), "retired agent").unwrap();
    fs::write(agents.join("loom-software-developer.md"), shipped).unwrap();
    fs::write(agents.join("my-agent.md"), "operator agent").unwrap();
    let target = temp.path().join("dotfiles/loom-linked.md");
    fs::create_dir_all(target.parent().unwrap()).unwrap();
    fs::write(&target, "kept in dotfiles").unwrap();
    std::os::unix::fs::symlink(&target, agents.join("loom-linked.md")).unwrap();

    let report = install_all(&paths, Some(SkillLayout::Core), false).unwrap();

    assert_eq!(
        report.pruned_agents,
        vec![agents.join("loom-foo.md"), agents.join("loom-linked.md")]
    );
    assert!(!agents.join("loom-foo.md").exists());
    assert!(agents.join("loom-linked.md").symlink_metadata().is_err());
    assert_eq!(fs::read_to_string(&target).unwrap(), "kept in dotfiles");
    assert_eq!(
        fs::read_to_string(agents.join("loom-software-developer.md")).unwrap(),
        shipped
    );
    assert_eq!(
        fs::read_to_string(agents.join("my-agent.md")).unwrap(),
        "operator agent"
    );
    assert_eq!(backup_count(&agents, "loom-foo.md"), 1);

    let before = snapshot(temp.path());
    let again = install_all(&paths, Some(SkillLayout::Core), false).unwrap();
    assert!(again.pruned_agents.is_empty());
    assert_eq!(snapshot(temp.path()), before);
}
```

It fails for the wrong behaviour: no prune leaves `loom-foo.md`; a prune that globs `*.md` removes `my-agent.md`; a prune that follows symlinks (or deletes via the target) breaks the `dotfiles` assertion; a prune that matches `loom-*` without `.md` re-removes the `.bak` copy on the second run and fails the snapshot.
