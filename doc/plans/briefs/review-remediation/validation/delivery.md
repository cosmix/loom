## CR-25 — Bash 4.2+ `${arg: -1}` in `poll-guard.sh` breaks macOS Bash 3.2

**Verdict:** REFUTED
**Evidence:** `loom-hooks/poll-guard.sh:30-36` is `*[smhd]) unit="${arg: -1}"; num="${arg%?}"`; the cited `:31-43` range is the whole `_loom_poll_rule_sleep`. The Bash manual (Shell Parameter Expansion, `${parameter:offset:length}`) says: if offset evaluates to a number less than zero it is used as an offset in characters from the end of the value, and "a negative offset must be separated from the colon by at least one space to avoid being confused with the `:-` expansion". So `${arg: -1}` (space before the minus) is the documented negative-offset form, present in bash 3.x including macOS's 3.2.57; `${arg:-1}` (no space) is the "use default 1" expansion and is the form that would misbehave. What arrived in Bash 4.x is negative substring length (`${x:o:-n}`) and negative indexed-array subscripts, neither used here. Basis: the Bash manual and bug-bash list excerpts (a 2016 report claiming 3.2 breakage used `${X:-2}`, the no-space form, and was withdrawn by its author). No Bash 3.2 interpreter exists in this environment (local bash is 5.3), so this was not executed on 3.2. The `hooks-macos` job (`ci.yml:400-440`) runs hooks on 3.2 but no test covers the suffixed units: `loom/tests/integration/hooks_poll_guard_cases.rs:4-32` tests only `sleep 5/29/30/300`, and the macOS job runs `loom-hooks/tests/run-all.sh` only, not the Rust integration tests.
**Fix seam:** none required. Optional coverage so a future edit cannot regress 3.2 silently: add a case to `loom-hooks/tests/poll-guard-subagent-waits.sh` (registered at `run-all.sh`) or a new `poll-guard-sleep-units.sh` registered in `run-all.sh`, asserting `sleep 1m` and `sleep 1h` produce the warning and `sleep 0.2m` does not, so the `hooks-macos` job runs it under 3.2.
**Regression test:** the optional shell case above; fixture helpers: see how `loom-hooks/tests/poll-guard-subagent-waits.sh` invokes `poll-guard.sh`. Does not fail today under bash 5 (nothing is wrong).
**Files a fix touches:** none (optional: `loom-hooks/tests/poll-guard-sleep-units.sh` new, `loom-hooks/tests/run-all.sh`).
**Size / tier:** drop the finding; optional S mechanical.
**Overlap:** `CR-68` (same file `poll-guard.sh`).
