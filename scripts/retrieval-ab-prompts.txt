# retrieval-ab-prompts.txt — replay corpus for scripts/retrieval-ab's metric 2
# (mean injected tokens per brief) and metric 3 (p95 hook wall time).
#
# Format: one prompt per line, "<class>|<prompt text>". Blank lines and lines
# starting with `#` are ignored. `<class>` is a free-form label the harness
# uses only to group its per-class breakdown in the report — it is never sent
# to `loom hook user-prompt`, only the text after the first `|` is.
#
# Every prompt is at least 24 characters (MIN_PROMPT_CHARS,
# loom/src/commands/hook/user_prompt.rs) so none is dropped by that floor
# before it even reaches retrieval — a prompt shorter than that would measure
# the length gate, not the emit floor or ranking this harness is about.
#
# Classes:
#   real      - real questions a developer would ask about THIS codebase.
#               The majority class. Sanity-checked against the live index
#               with `loom knowledge context --query ... --json` while this
#               corpus was written — every one returns at least one item.
#   collision - doc/PROPOSAL-retrieval-precision.md section 2's measured
#               failure specimens: prose words colliding with symbol names, a
#               filesystem path extracting spurious terms, and vague
#               quality/performance wording. Three of these five are the
#               EXACT queries loom/eval/retrieval-cases.yaml's
#               prose-symbol-collision-*/filesystem-path-* cases pin as
#               `forbid` regressions, so this class also cross-checks metric 1
#               against metric 2/3 on the same specimens.
#   machine   - machine-generated payloads (task-notification XML, a
#               background-agent-stopped notice, a Caveat: line, a nested
#               system-reminder). A.4 (loom/src/commands/hook/user_prompt.rs,
#               `parse_prompt`) is specified to decline these outright on the
#               CURRENT binary (no retrieval attempt, no brief, near-zero
#               wall time); the BASELINE binary predates A.4 and retrieves
#               against them like any other prompt. That asymmetry is itself
#               one of the headline results this harness exists to show.
#   weak      - genuinely vague prompts with no identifier-shaped or rare
#               vocabulary, long enough to clear MIN_PROMPT_CHARS. These
#               SHOULD now be met with silence (A.5's emit floor) rather than
#               a low-confidence brief.
#
